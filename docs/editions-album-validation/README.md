## 动效拆解

公开模块 `albumConstants-CGvpvu9n.js` 给出 hoverLiftDuration = 1000、hoverDropDuration = 400、activeAnimationDuration = 700，单位毫秒。页面主模块的 hover 使用 easeOutQuart 抬起、easeInQuart 放回，并叠加 spring 倾斜。点击使用分段曲线推进到镜头前；不是单纯放大图片。

本次参考页抽出采样得到 32 帧，约 30–781 毫秒。时间是点击调用返回后的采样时间，含工具与截图开销，不是浏览器性能基准。

| 关键帧 | 观察 |
| --- | --- |
| 约 30 ms | 悬停封套已经离开搁板，底部 Open / Details 尚可见 |
| 约 194 ms | 向中间移动，封套开始放大 |
| 约 382 ms | 背景开始虚化，左侧说明浮现 |
| 约 614 ms | 封套接近中央目标尺寸，操作按钮出现 |
| 约 781 ms | 动画落定，保留背景唱片架和左侧说明 |

另保存归位 32 帧及精确采样时间。`reference-open-filmstrip.jpg` 和 `reference-return-*.png` 可直接对照。

原生实现采用 SwiftUI 的透视旋转、阴影及 matchedGeometryEffect：悬停抬高 22 点并轻微倾斜，进入 1 秒、离开 0.4 秒；抽出和归位 0.7 秒；空格翻面，Escape 放回。尊重系统减少动态效果设置。使用现有照片及相册标题，不复制 Shopify 的品牌素材或 WebGL 模型。材质、反射和弹性细节是原生近似，并非逐像素重建。
