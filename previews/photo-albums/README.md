# 独立相册预览

打开 `相册预览.app`。这是独立的 macOS 窗口，使用本地摄影样片，无需联网浏览。

- 相册库 → 四行流动照片墙 → 点击照片查看旁注 → 双页阅读。
- 可返回相册库、切换相册、左右拖动照片墙、暂停流动、切换上一张/下一张。
- 描述编辑保存在该预览的本地 WebKit 存储中。示例相册共用同一组摄影样片。
- 照片来自 Unsplash，具体原图地址见 `photo-sources.json`；旁注为虚构示例。
- 布局与动画沿用 Mac Sleeve 实测：截图基准 1814 × 1518，四行各 379.5，行首错位 151/296/62/207。速度约 22.096 参考像素/秒，缩放后等比例变化。

此目录仅包含本次预览，未改动已有 SwiftUI 与 NSH 原型。
